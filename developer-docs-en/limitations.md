# Capabilities and limits

The following boundaries describe the current Developer Edition plan. They will be confirmed against the delivered product at release.

| Item | Developer Edition |
| --- | --- |
| Deployment | Docker Compose only |
| Meta | One Meta |
| Service groups | One pre-initialized service group |
| Hosts | Only one host can be added |
| Parts | One Part |
| Replicas | One replica; replica count cannot be changed |
| Product license file | No application or configuration required |

Not requiring a license file does not remove software license terms or database authentication and authorization.

## Details to follow

Supported platforms, hardware requirements, image addresses, the initialized service group name, and upgrade paths will be documented with deployment instructions and release information. No unverified installation commands are provided here.

The supported GQL and API scope will be documented for each product version.
