# Documentation versions

Only **Preview** is currently available. It is used to review the site and content and does not correspond to a released Developer Edition image.

The version menu lists documentation actually available on this site. Released versions will have separate content, search indexes, and AI documentation entry points.

## Choose your version

Select documentation matching your installed product. Features introduced in newer releases may not work in older versions.

Language switching preserves the version and page. If a page is absent from a selected version, the site shows a not-found page; use that version's homepage to continue.

## Maintenance

Documentation is organized by major and minor product version. Patch-specific differences are noted in the text. Existing versions can receive corrections; new features appear only in applicable versions.
