# Contribute

Help improve [nebula-developer-docs](https://github.com/vesoft-inc/nebula-developer-docs) by reporting problems and suggesting changes.

## Edit a page

1. Select the edit button to open the matching source file.
2. Sign in to GitHub, edit the Markdown, and submit a pull request.
3. Maintainers review and merge the changes, then publish the updated site.

Proposed edits are reviewed before they reach the live website.

## Report an issue

Include the page URL, documentation version, problem, and expected result in a [GitHub issue](https://github.com/vesoft-inc/nebula-developer-docs/issues). Do not include credentials or private data.

See the repository README for local preview instructions. Contributions and builds do not require the private Enterprise documentation repository.
