Give these URLs to an AI tool that supports web access or document uploads. Ask it to use the specified version and cite its sources.

For example: “Use the {{nebula.name}} docs to explain the product limits and identify deployment information that is not yet available.”

This preview includes [Docker Compose deployment](get-started/deploy.md) and [a first query](get-started/first-query.md), using nightly images that await end-to-end validation. AI tools should not invent unconfirmed requirements, compatibility claims, or steps from other versions or Enterprise documentation. Discovery after public launch depends on individual search and AI services.
