# {{nebula.short_name}}简介

{{nebula.name}}提供一个单机图数据库环境，帮助您学习如何表示数据之间的关系、编写查询，并验证自己的应用。

例如，使用内置的 `movie` 数据集，您可以查询“某部电影有哪些演员”。数据库中，演员和电影称为**点**，它们之间的“参演”关系称为**边**。

## 适用场景

- **学习图数据库和 {{gql.name}}。** {{gql.name}} 是操作图数据的查询语言。您可以创建图、写入点和边，再查询它们之间的关系。
- **开发和验证应用。** 在单机环境中尝试数据建模、查询和应用连接。
- **准备自动化测试。** 将开发环境用于功能验证。具体接入方式和客户端版本需与所用产品版本匹配。

{{nebula.short_name}}面向学习、开发与测试。软件允许的使用范围以随产品提供的许可条款为准。

## 使用路径

第一次使用时，直接进入[快速开始](get-started/index.md)。教程按“准备环境 → 启动数据库 → 连接 → 加载 movie 并查询”的顺序展开，不需要先读完所有概念。

如果您想先了解产品，可以按下面的顺序阅读：

2. [功能与限制](limitations.md)：确认{{nebula.short_name}}是否适合您的使用场景。

## 部署说明

{{nebula.short_name}}仅支持 Docker Compose 部署。Docker 用容器运行软件；Docker Compose 根据配置文件一起启动所需的容器。单机部署不等于只运行一个容器。

配套 Docker Compose 文件会在首次启动时自动初始化服务组，也就是一组配合工作的数据库服务。您无需先手工创建服务组，也不需要申请或配置产品 License 文件。固定的部署限制见[功能与限制](limitations.md)。
