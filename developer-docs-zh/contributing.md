# 参与贡献

欢迎在 [nebula-developer-docs](https://github.com/vesoft-inc/nebula-developer-docs) 报告问题和提出改进。

## 修改页面

1. 点击页面右上方的编辑按钮，进入对应源文件。
2. 登录 GitHub，修改 Markdown，提交 Pull Request（修改申请）。
3. 维护者审核合并后，通过发布流程更新网站。

编辑功能不会让未经审核的修改直接出现在正式网站上。

## 反馈问题

在 [Issues](https://github.com/vesoft-inc/nebula-developer-docs/issues) 提供文档链接、文档版本、问题描述和预期结果。请勿上传密码或私有数据。

本地预览方式见仓库 README。普通文档贡献和构建无需访问企业版私有仓库。

## 许可说明

仓库许可证尚待维护者确认。公开可读与开放修改申请不等同于已授予任意转载或分发权限；正式开源发布前应补充明确的许可证。
