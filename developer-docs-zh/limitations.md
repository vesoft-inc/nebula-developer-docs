# 功能与限制

以下为开发版当前规划的使用边界。正式版本发布时，将结合交付结果确认。

| 项目 | 开发版 |
| --- | --- |
| 部署方式 | 仅 Docker Compose |
| Meta | 单 Meta |
| 服务组 | 单 Service Group，预先初始化 |
| 主机 | 只能添加一个 Host |
| Part | 单 Part |
| 副本 | 单副本，不支持调整副本数 |
| 产品 License 文件 | 无需申请或配置 |

“无需 License 文件”不表示没有软件许可条款，也不等同于关闭数据库用户认证和权限管理。

## 尚待补充

支持的平台、硬件要求、镜像地址、预初始化服务组名称和升级路径，将在部署文档与正式发布说明中补充。当前不提供未经验证的安装命令。

GQL 和 API 的具体支持范围将在对应版本参考文档中说明。
