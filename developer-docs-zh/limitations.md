# 功能与限制

在部署前，先确认{{nebula.short_name}}的固定配置是否满足您的学习、开发或测试需求。

!!! note "适用范围"

    以下内容描述{{nebula.short_name}}规划的使用边界。本站仍为预览文档，正式支持范围需与发布的产品版本一起确认。

## 部署限制

| 项目 | {{nebula.short_name}}范围 | 对您的影响 |
| --- | --- | --- |
| 部署方式 | 仅 Docker Compose | 使用{{nebula.short_name}}配套的 Docker Compose 文件部署 |
| 主机 | 单机，只能注册一个主机地址 | 不能增加主机来扩展这个实例 |
| 服务组 | 只有一个，预先初始化 | 无需自行创建服务组 |
| Meta 服务 | 只有一个 | 不提供多 Meta 部署 |
| 数据分片 | 只有一个 | 不能通过增加数据分片来分散存储数据 |
| 副本 | 只有一份，不支持调整数量 | 不能通过增加副本获得故障切换能力 |
| 集群同步 | 不支持 | 不能配置实例之间的集群同步 |

Meta 服务负责管理数据库的元数据，例如图的定义。数据分片是数据库内部划分图数据的逻辑单位，副本是同一份数据的复制份数。首次使用时，无需修改这些配置。

!!! warning "单机、单副本不提供高可用保障"

    主机或存储发生故障时，不能依靠另一个副本继续提供服务。请勿将{{nebula.short_name}}用作需要高可用保障的业务环境。

## 产品 License 文件与登录

无需申请或配置产品 License 文件。数据库登录与产品 License 文件无关，连接数据库时仍需使用用户名和密码。

## 待确认的支持范围

下列信息尚未在本预览中确定，请勿据此假设功能无限制或已经可用：

- **多用户和访问权限：** 暂不承诺用户之间具有数据隔离能力。
- **数据容量：** 尚未公布容量上限、计算方式和达到上限后的行为；没有公布上限不等于无限容量。
- **客户端和工具：** SDK、连接器、可视化及 AI 工具需要分别确认兼容版本。
- **更新：** 暂无经过验证的升级或降级路径。

{{nebula.short_name}}镜像支持 AMD64（x86_64）和 ARM64 处理器架构。操作系统和安装文件需要与发行版本对应。部署前请检查[使用 Docker Compose 部署](get-started/deploy.md)。
